# 画廊

<!-- doc-locale: zh-CN -->
> [English](README.md) | **简体中文**

画廊通过共享照片库能力读取照片。它从不接收文件系统路径，并且只能在明确确认后才能删除照片。

量产照片库不会按照片数量执行淘汰。Gallery 只缓存当前包含八个 ID 的页面和一个
320x170 视图。Camera JPEG 原图由 appd 解码和裁剪，绝不会复制到 Gallery 的 WASM
内存中。

![画廊空的库状态](assets/screenshot.png)

## 控制按钮

- F 或 Z: 移到上一张照片，从第一张循环到最后一张。
- X 或 C: 切换到下一张照片，从最后一张切换回第一张。
- 上、下、左或右也会在正常浏览器中改变照片。
- 进入照片：打开其全屏原图视图。
- 进入原始视图：循环适配，半分辨率和1:1缩放。
- 原视图中的方向键：移动视口。
- 原视图中的退格: 返回到正常浏览器。
- 在正常浏览器中删除：打开删除确认。
- 确认选择中的上一个/下一个键用于选择取消或删除。
- 输入: 确认选定的操作。
- 当库为空时输入：刷新库。

原始键和它们的Fn组合在产生相同的键码时都被接受。应用程序请求`photos.read`用于查看和`photos.write`用于删除。

## 在模拟器中运行

```sh
cargo run -p cp0ctl -- run examples/gallery \
  --duration 250 --permissions allow \
  --output target/gallery.ppm
```

画廊是产品镜像中包含的八个应用程序之一，是一个不可卸载的量产内置应用。
