## 原则

Home 条目是受信任的系统表面，但 Shell 保持非特权状态。硬件更改通过有符号整数设备服务进行；应用程序管理通过 appd。当其支持的能力不存在时，一行显示为不可用。本地模拟可以测试所有状态，但不得暗示未验证的硬件写入在 V0.6 中已经生效。

所有屏幕分辨率为320x170，保持一个前台视图，最多使用四行可见内容，滚动时保留选择，并处理上/下、Enter和返回。左/右仅在行可编辑时改变边界值。

## 设置信息架构

### 连接性

- Wi-Fi: 无线状态，链接状态，当前SSID/IP，扫描，保存网络，
连接/断开和忘记。凭据只能提交给根拥有的网络代理，并且绝不能返回给Shell。
- 飞机模式：一项交易会禁用Wi-Fi、蓝牙（如果存在）和可选的LoRa无线模块。有线以太网仍然可用，并且会标记为有线以太网。
- 网络详细信息：接口，IPv4，网关，DNS，信号和MAC隐私状态。
- 蓝牙、热点和VPN仅在它们的能力提供者存在后出现。
- 有线以太网、代理和私有DNS是网络细节模型的一部分；
蜂窝网络相关的概念如SIM卡和漫游故意被省略。

### 显示和外观

- Fn+U/Fn+I 集成的亮度调节和临时级别叠加。
- 深色、亮色和高对比度主题。
- 屏幕超时：30秒、1分钟、5分钟或从不。
- 文本密度和旋转是未来选项；在每种受信任提示和SDK界面能够跟随选定几何形状之前，它们都不会被暴露。
- 夜灯、状态栏可见性和可访问性文本缩放需要一个跨 compositor 的外观合同，而不是每个应用的覆盖。

### 声音

- 使用Fn+A/Fn+S/Fn+D快捷键调节媒体音量和静音。
- 系统/关键声音和选定的输出路径。
- USB媒体传输需要当前所有者的密码，仅暴露隔离的`CP0-MEDIA`交换镜像，原子化导入验证过的音乐，并只读导出照片副本。它不启用开发者模式或所有者SSH shell。
- 麦克风状态是信息性的；应用程序录音仍然需要权限调解，并且在权限被拒绝时不能全局启用。
- 勿扰模式和通知声音需要通知代理和服务媒体代理共享一个有界焦点策略。

### 摄像头

- 首选捕获分辨率、旋转和镜像策略。
- 当前的能力代理服务只有一个320x170 RGB565的合同。更大的分辨率
在代理服务的ABI和资源预算改变之前仍然无法明显使用。
- 相机权限访问在隐私设置中管理，不是在这里静默授予。

### 电源和电池

- 充电状态、容量、电压、有符号电流和估算电池功率。
- 电池节能和充电限制是能力 gating 的未来控件。
- 关机和重启使用可信的确认UI和实现的仅Shell cp0-powerd 固定动作代理服务。

### 应用、存储和隐私

- 每应用版本，安装时间，包字节，私有数据字节，显示模式，生命周期状态和声明权限。
- F3 Tasks 保持一个前台视图，同时最多水平堆叠十个 160x85 的卡片。左/右选择一个任务，上/下选择其 OPEN/STOP 动作，回车执行它，空格直接停止选定的任务，Esc/Home 返回到受信任的主页表面。
- 任务卡片按最近激活顺序排列，而容量回收则遵循严格创建顺序的先进先出(FIFO)。检查点或崩溃的任务仍然是一个活跃的逻辑任务，并阻止包替换，直到显式关闭。
- 启动/恢复，停止，权限重置和卸载需确认。
卸载会移除可执行包版本和权限决定，但保留私人数据以便后续明确的`Clear data`操作。
- 全局权限概览、文档访问历史和存储摘要计划在其有界查询API存在时作为单独的设置页面。
- 通知策略、默认意图处理程序和摄像头/麦克风/网络访问历史需要由appd提供的审计API。Shell绝不能检查应用程序私有数据以构建这些视图。
- 在 compositor、Runtime 和经测量的 CM0 集成完成前，实时可信缩略图、首帧前恢复和后台资源压力行为都必须保持明确的未开放状态；本地占位卡不是真机证据。

### 系统

- 关于：电路板, 操作系统构建, 内核/启动标识, 运行时间和更新渠道。
- 硬件诊断：显示、键盘、音频、摄像头、电池和I2C总线。
- 日期/时间、语言、无障碍功能、OS更新和支持包在此处提供。
自动时间同步和更新控制需要专用服务。
- 键盘布局、备份、重置选项、许可证和本地诊断属于能力代理服务行。云账户和 cellular 设置不是 V0.6 的产品概念，并且故意被排除在外。

### 安全、策略和开发者选项

- 管理权限和Store/app/能力限制。
- 开发者模式和恢复启动保留策略锁和确认。
- 屏幕锁定、加密和凭证在没有产品认证设计和验证启动/存储先决条件的情况下不会被采用。
- 安装源、信任证书、安全审计历史和工厂复位需要根拥有的策略端点和破坏性确认。

## 特权服务边界

本地UI模型不是硬件权限。在任何V0.6设置变得可写之前，一个根拥有服务必须暴露一个窄请求协议，验证调用者为受信任的Shell，应用策略，返回观察状态并记录一个有界的审计记录。计划的提供者是：

| 提供者 | 拥有 | 不得暴露 |
| --- | --- | --- |
| 网络代理 | Wi-Fi 搜索/连接/忘记，空中交易，DNS/代理 | 资质，原始 NetworkManager 或 netlink 控制 |
| 显示代理服务 | 背光级别、超时时间和 compositor 窗口状态 | 原始 sysfs/DRM 握手 |
| 声音代理 | PCM，输出音量/静音，键声音和焦点策略 | 无限制的ALSA设备或格式选择 |
| Owner USB Media 代理服务 | 固定交换镜像 MSC，限制音乐导入和只读照片副本 | 活动分区、块设备、System Shell、应用部署、调用方提供的路径或照片修改 |
| 相机代理 | 捕获配置和方向策略 | 原始 V4L2 设备 |
| 权力代理服务 | 实现了重启/关机；未来支持充电策略 | 随意的 systemd 或 sysfs 操作 |
| 系统代理服务 | 时间、更新、备份/重置和支持包任务 | 系统命令或文件系统路径 |

每次修改请求都会先进行能力查询。不支持的控件将以 `UNAVAILABLE` 显示；本地模拟从未通过生产 Shell 入口点启用。

## 官方键盘映射

系统遵循 `https://cardputer.cc/#/documents/cp0-keys`:

| 组合 | Linux 键/动作 | 所有权 |
| --- | --- | --- |
| Fn+1..0, Fn+O, Fn+P | F1..F12 | F1 回家, F2 返回, F3 任务, F4 电源; F5..F12 传递给前台应用 |
| Fn+Q/W/E | 播放/暂停，上一曲，下一曲 | compositor 全局媒体动作 |
| Fn+U/I | 亮度减小/增加 | compositor 全局显示操作 |
| Fn+A/S/D | 关闭音量/降低/增大 | 调整全局声音 |
| Fn+F/Z/X/C | 上/左/下/右 | 标准导航；字母也可以导航受信任的非文本视图 |
| Fn+H | 帮助 | 可信的帮助叠加或前台应用的帮助事件 |
| Fn+J | 打印屏 | 可信的截图请求，带有限定的目的地 |
| Fn+K/L/M | 回家/页面上滚/页面下滚 | 前台标准键；Home 保持与 OS 回家/F1 不同 |
| Fn+B/N | 插入/结束 | 前台标准键 |
| Fn+删除键 | 删除 | 前台标准键 |

ESC 短按保持为 Back，当 Shell 聚焦时。文档中长按 Home 的行为属于键盘驱动程序/ compositor，必须不要在每个应用中实现为不可靠的用户空间定时器。
