# Archived Release Notes

The following release body was backed up from the GitHub Release

## CardputerZero OS v0.1.0-rc.1

The first public release candidate for CardputerZero V0.6. It includes the OS image build pipeline, System Shell, application runtime, SDK 1.1, App DevKit, development Skill, and Store foundations.

### Release Assets

- Production-access CardputerZero OS image
- SHA-256 checksum manifest and image profile information
- Linux App DevKit archive and checksum
- Standalone App development Skill archive and checksum
- Apache-2.0 license and third-party notices

### Release Candidate Status

This is a release candidate and does not represent completed production hardware acceptance. Validate V0.6 hardware behavior, 24-hour stability, update and recovery paths, and release-asset checksums before production deployment.
