# CardputerZero OS v0.1.0-rc.1

这是面向 CardputerZero V0.6 的重新发布候选版本说明。旧正文保留在
`v0.1.0-rc.1.md` 中作为历史备份。本版本是工程候选版本，不是已经完成生产认证的固件。

## 主要内容

- 面向树莓派 CM0、512 MB 内存和 320x170 LCD 的精简 Debian/systemd OS，使用键盘优先的
  System Shell，不依赖完整桌面环境。
- 可信 compositor 和单前台应用模型，包含 Home、Apps、Tasks、Settings、Store、电源、
  熄屏和恢复流程。
- 基于 WebAssembly 的应用运行时隔离，包含每应用身份、cgroup、namespace、seccomp、
  私有存储、类型化能力代理和 Owner 权限决策。
- SDK 1.1、WIT ABI 契约、Rust 和 C/C++ 绑定、PC 模拟器、`cp0ctl` 工作流、示例应用以及
  可迁移的 App DevKit。
- 签名 `.capp` 包、Developer Mode 部署、Store 校验和回滚基础、只读根/数据分区基础设施以及
  恢复工具。
- 稳定的 Release 镜像命名和 ARM64 原生构建路径，发布资产名称不再依赖 pi-gen 的日期前缀。

## Release 资产

- `cardputerzero-os-v0.1.0-rc.1-cp0-os-production.img.xz`：CardputerZero V0.6 生产访问镜像。
- `cardputerzero-os-v0.1.0-rc.1-cp0-os-production.info`：构建和镜像配置资料。
- `SHA256SUMS`：压缩镜像的 SHA-256 清单。
- `cardputerzero-app-devkit-*-aarch64-unknown-linux-gnu.tar.xz` 及其 `.sha256`：可迁移的
  Linux App DevKit 压缩包。
- `cardputerzero-build-app.tar.xz` 及其 `.sha256`：独立的 App 构建 Skill 压缩包。

DevKit 压缩包内包含 Apache-2.0 许可证、第三方声明、SDK、模拟器、schema、示例和开发文档。

## 使用前校验

在包含下载资产的目录中执行：

```sh
sha256sum -c SHA256SUMS
sha256sum -c cardputerzero-app-devkit-*-aarch64-unknown-linux-gnu.tar.xz.sha256
sha256sum -c cardputerzero-build-app.tar.xz.sha256
```

检查 `.info` 文件，并在备份镜像时保留原始 checksum 文件。在下述硬件门禁关闭前，只应将镜像
烧录到可丢弃的介质上。

## 访问和安全默认值

镜像使用 `production` 访问配置。镜像中没有共享登录密码或预置 SSH 密钥。SSH 和不受限的
Owner SSH Shell 默认关闭。Owner 可以通过物理操作打开 Developer Mode、配对电脑，并通过受限
部署通道授权签名 SDK App；这不会授予 Bash、root、sudo 或设备的环境权限。

Developer Mode 和独立的 Owner SSH Shell 是两个不同的控制项。恢复访问需要单独构建的恢复镜像
和物理启动授权流程。共享 Linux 内核意味着应用隔离是纵深防御，而不是数学意义上的绝对隔离。

## Release Candidate 状态

候选版本已具备主机端构建、镜像配置、包、SDK 和应用运行时检查，但还不是生产验收签字。在批量或
长期部署前，还需要完成 V0.6 真机冷启动、LCD 方向和颜色、摄像头/音频、访问配置默认状态、正常
重启和断电恢复、只读根/数据持久化、Store 操作、性能以及 24 小时稳定性和 SD 写入上限检查。
权威状态和验收证据记录在 [`docs/ROADMAP.md`](../ROADMAP.md) 及其关联阶段文档中。

## 源码和可复现性

Release 由固定 Git tag 触发的发布工作流构建，使用锁定的 Rust 1.85.1、BSP 和 Runtime 输入。
不要把文件名、网络地址或单次主机测试当作经过认证的 checksum 和真机验收的替代品。
