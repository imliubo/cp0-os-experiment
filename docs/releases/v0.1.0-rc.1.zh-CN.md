# 已归档的 Release 说明

以下内容是在替换 GitHub Release `v0.1.0-rc.1` 的 tag 和 Release 之前备份的中文译文。英文文件保留了 GitHub 上的原始 Release 正文。

## CardputerZero OS v0.1.0-rc.1

这是面向 CardputerZero V0.6 的首个公开候选版本，包含 OS 镜像构建流水线、System Shell、应用运行时、SDK 1.1、App DevKit、开发 Skill 和 Store 基础能力。

### Release 资产

- 可用于生产访问的 CardputerZero OS 镜像
- SHA-256 校验和清单及镜像配置资料
- Linux App DevKit 压缩包及校验和
- 独立的 App 开发 Skill 压缩包及校验和
- Apache-2.0 许可证和第三方声明

### Release Candidate 状态

这是候选版本，不代表生产硬件验收已经完成。在部署到生产环境前，请验证 V0.6 硬件行为、24 小时稳定性、更新与恢复路径，以及 Release 资产校验和。
