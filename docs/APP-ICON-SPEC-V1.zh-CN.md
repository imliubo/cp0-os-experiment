# CardputerZero 应用图标规范 v1

<!-- doc-locale: zh-CN -->
> [English](APP-ICON-SPEC-V1.md) | **简体中文**

Apps 屏幕有两个用户可选的视图。在 Apps 根位置按 Tab 键可以在列表和网格之间切换，而不改变选中的应用。

## 网格几何

- 视窗大小为320x170像素。
- 网格模式包含四列两行，每页八个应用程序。
- 每个单元格是72x57像素，带有四像素的水平间距。
- 图标槽位正好是40x40像素。
- 艺术品必须保留两像素的安全区域，建议保留36x36像素的视觉足迹。
- 应用标签是一行，并在紧凑网格中裁剪为十个ASCII字符。完整名称在列表和应用详情中可用。

## 状态和选择

图标艺术作品不编码进程状态。

- 运行中：40x40 图标插槽轮廓为绿色。
- 停止、启动或失败：图标插槽轮廓为灰色。详细状态在列表和应用详情中仍然可见。
- 选中：单元格使用深色凸起的表面和单独的黄色轮廓。

这种分离确保了键盘选择不会被误认为是后台应用程序运行。

## 艺术作品来源

八个系统应用使用内置的一色过程性图符。
没有系统图符的应用接收一个大写的首字母缩写，其来源于显示名称。未来的清单修订可能会添加打包的位图艺术作品；它必须保持相同的40x40插槽和状态轮廓行为。
