# 长按ESC键返回主屏幕

<!-- doc-locale: zh-CN -->
> [English](ESC-LONG-PRESS-HOME.md) | **简体中文**

可信的Weston策略拥有ESC手势。应用程序从未接收绑定键并且不运行手势计时器。按下开始一个 compositor 状态机器：

- 在800毫秒之前释放会发送恰好一个Back动作；
- 保留持有800毫秒后发送恰好一个Home动作；
- Home 不发送 Back。

政策会以受限的20毫秒间隔轮询Weston的权威按键数组。它不信任重复事件、墙钟时间或Shell提供的持续时间。重复按键不能延长阈值。信任的Shell、键盘或 compositor 的丢失会取消待处理的手势。

家使用现有的认证 System Shell 协议动作，并在交付前强制信任的完整叠加。不需要协议版本更改。`KEY_HOME`，由`Fn+K`产生，继续作为全局密钥未注册并传递到前台应用。

本地测试锁定短发布，确切阈值，重复按下，
回退计时和取消行为。compositor profile 会锁定计时器、按键所有权和镜像构建来源。
V0.6 真机验收仍需测量阈值，并分别确认 Home、标准应用和沉浸式应用中的 ESC 短按与
长按行为。
