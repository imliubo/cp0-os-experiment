## 产品边界

五个Home条目是可信任的System Shell视图。它们是OS的一部分，并不是SDK应用程序。一次只显示一个视图，所有输入都是通过键盘驱动的，并且每个视图都适应固定在21像素信任状态栏下方的320x170 framebuffer。

首次发布仅暴露具有现有受信任控制路径的数据和操作。屏幕亮度使用Shell独有的`cp0-displayd`路径，并且其V0.6 sysfs控制已通过物理读取验证。Wi-Fi配置、保存网络管理和空闲超时仍然需要新的特权提供者，且故意不表示为可用控制。闪存的镜像缺少BCM43439固件；在未来的Wi-Fi代理可以接受之前，必须先闪存镜像包修复。

## 查看规范

### 应用

- 显示由 appd 返回的每个应用，包括名称、生命周期状态和列表截断。
- 上下选择，Enter键启动或继续，右键打开详情，返回键返回首页。
- 详细信息显示版本、应用ID、标准/沉浸显示模式和生命周期状态。Enter键启动已停止的应用或停止正在运行的应用。
- 在 appd 柜单刷新后保留选择，并暴露显式的空、开始和失败状态。

### 仓库

- 显示审核过的目录，包含可用、更新、队列、下载中、安装中、已安装和失败状态。
- 刷新会更新目录。Enter会打开详细信息，然后通过cp0-stored请求一个有界的安装/更新。
- 详情显示版本、摘要和声明的SDK权限。列表暴露陈旧的、不可用的、未配置的、加载中的、空的和截断的状态。

### 设备

- 概览显示Cardputer Zero V0.6 / CM0 的身份信息、OS 版本、运行时间以及CPU 温度。
- 资源显示可用/总内存，可用/总持久存储空间和电池容量。
- 左/右切换两个固定页面。缺失的遥测信息显示为 `UNKNOWN`；它永远不会成为伪造的值。

### 网络

- 状态显示在线/离线/仅链接状态，选定的非回环接口和IPv4地址。
- 细节展示接口、链路状态和地址在一个稳定的两页布局中。
- 网络视图保持只读。受信任的 Wi-Fi 无线电、飞行模式、扫描和连接控制都在设置中 live 并使用专用的连接性/配置代理服务；应用程序既不接收 NetworkManager 访问权限也不接收凭据。

### 设置

- 开发者模式和恢复启动仅受 bounded appd 设备策略控制。
启用任一模式需要确认；禁用则立即生效。
- 连接性暴露了 Wi-Fi 无线网络、飞行模式以及一个带有遮罩的 WPA 身份验证输入的网络选择器。
- 安全暴露了当前密码认证的所有者密码替换
以及独立的 Owner SSH Shell 开关；它绝不授予 root 或 sudo 权限。
- 一个策略行打开一个只读详细页面，显示管理权限、Store 安装、应用启动和能力限制。
- 锁定或不可用的设置是明显不可操作的。返回关闭详细/确认信息后返回首页。
